## 2. Présentation du projet

### 2.1 Objectif principal (en une phrase)

Développer un agent IA qui permet de faire du conseil immobilier avec l'utilisation d'outils externe

### 2.2 Problématique / besoin utilisateur

Assister les agents immobilier dans leur recherche de tous les jours (estimation, historique, environnement immobilier)

### 2.3 Périmètre fonctionnel
